# YouTube Archive Queue

YouTubeチャンネルの「動画」「ライブ」「Shorts」タブに現在表示されている順番を、そのまま連続再生するChrome拡張です。

## インストール

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパー モード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. この `youtube-archive-queue` フォルダーを選択する

## 使い方

1. YouTubeのチャンネルで「動画」「ライブ」または「Shorts」タブを開く
2. YouTube側の並べ替えで「古い順」などを選ぶ
3. 「新しい順」または「古い順」を選び、右下の「キューを作成して再生」を押す
4. 拡張が一覧を最後まで読み込み、先頭の動画から再生を始める

Chromeツールバーの拡張アイコンを押すと、専用のキュー管理ページが新しいタブで開きます。YouTube上の「管理」ボタンからも、バックグラウンド経由で安全に開けます。

管理ページではチャンネルごとに合計・未視聴・視聴済み・除外数と現在位置を確認でき、「続きから再生」で保存位置からYouTubeを開けます。チャンネルの詳細では検索、フィルター、ドラッグ並べ替え、順番反転、複数選択、視聴状態、除外・復元を編集できます。

管理ページの「新着を取得」は対象チャンネルのYouTubeタブを開き、保存済み動画に到達するまで差分を自動取得します。

一度作成したキューはチャンネルごとにローカル保存され、次回は「続きから再生」できます。「新着を更新」は新しい順の先頭から確認し、保存済み動画に到達した時点で取得を止めます。必要な場合だけ「全件を再取得」できます。

再生画面の右下から前後への移動と、アニメーション付きの大きなキューマネージャーを開けます。キューマネージャーではサムネイル付き一覧、タイトル検索、視聴済み・未視聴フィルター、動画の削除、ドラッグハンドルによる並べ替え、順番の反転ができます。大量のキューは100件ずつ表示します。

「閉じる」はキューマネージャーだけを閉じ、「最小化」は右下に小さな再表示ボタンを残します。キュー自体を止める場合はキュー一覧ヘッダーの「連続再生を停止」を使います。停止後も保存済みキューから再開できます。

再生コントローラーはタイトル右上に、前へ・再生／一時停止・次へ・一覧・最小化のSVGアイコンを配置しています。再生状態に応じて中央アイコンが切り替わります。管理ページへのボタンは大きなキュー一覧のヘッダーにあります。

動画を全画面表示している間は、YouTubeの再生コントロールと重ならないよう拡張のUIを自動的に隠します。全画面を終了すると再表示されます。ドラッグで並べ替える際は、移動元と途中の動画が滑らかに移動します。

再生位置は約5秒ごとに保存され、次回その動画を開いたときに続きから再生します。最後まで再生した動画は視聴済みになり、「視聴済みを自動スキップ」が有効な場合は次回以降の連続再生から除外されます。

各動画は手動で視聴済み・未視聴を切り替えられ、「ここまで視聴済み」で先頭から選択位置までを一括変更できます。チェックボックスで複数選択し、視聴済み・未視聴・削除をまとめて実行することもできます。サムネイル下には保存された再生進捗を表示します。

削除済み・非公開などで再生エラーを検出した動画は再生不能として記録し、自動的に次の未視聴動画へ進みます。キュー外のYouTube動画を開いた場合は、「キューに戻る」または通知を閉じることができます。

キューマネージャーの「バックアップ」で全チャンネルの保存済みキューをJSONに書き出し、「復元」で既存データへ読み込めます。

取り込み時にはチャンネル一覧に表示された配信日の文字列を保存し、動画を再生したときにページから正確な公開日を取得できれば更新します。どちらもJSONバックアップに含まれます。

動画を削除すると「キューから除外」された状態になり、グレーアウトしたまま一覧とJSONバックアップに残ります。「元に戻す」または「削除をすべて元に戻す」でいつでも復元できます。除外した動画は連続再生の対象になりません。

キューと現在位置はChromeのローカルストレージにのみ保存され、外部へ送信されません。

配信予定・プレミア公開予定など、まだ開始されていない枠はキューから自動的に除外されます。配信中の枠と終了後のアーカイブは対象です。

## 現在の制限

- YouTubeの画面構造が変更されると、動画一覧を取得できなくなる場合があります。
- 非公開・削除済みなど、チャンネル一覧に表示されない動画は対象外です。
- 一覧の読み込み中はページを移動しないでください。
- 取得上限は10,000件です。
