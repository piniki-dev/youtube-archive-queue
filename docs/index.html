YouTubeチャンネルのライブアーカイブをキューに保存し、古い順でも新しい順でも連続再生できます。

ベータ版をダウンロードインストール方法

FEATURES

アーカイブ視聴に必要なものをひとつに

01

古い順・新しい順

ライブアーカイブを取り込み、好きな順番で連続再生します。

02

続きから再生

動画ごとの再生位置と視聴状態をローカルに保存します。

03

キューを管理

検索、除外・復元、ドラッグ並べ替え、バックアップに対応しています。

HOW TO USE

簡単な使い方

  1. 視聴したいYouTubeチャンネルのページを開く
  2. 右下のArchive Queueで「新しい順」または「古い順」を選ぶ
  3. 「ライブアーカイブを取り込む」を押す
  4. 自動で「ライブ」タブへ移動して取得し、連続再生が始まる

現在はライブアーカイブ専用です。動画とShortsは取り込みません。1チャンネルにつき1つのキューを保存します。

INSTALL

ベータ版の導入

  1. Releasesから最新版のZIPをダウンロード
  2. ZIPを任意のフォルダーへ展開
  3. chrome://extensionsでデベロッパーモードを有効化
  4. 「パッケージ化されていない拡張機能を読み込む」から展開先を選択

Chrome Web Store公開前のため、更新は拡張機能のお知らせから手動で行います。
